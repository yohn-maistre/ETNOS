# Where we are, and what's left before the demo

15 November 2026. Proposal upload is 18–19 November. Showcase is 4–5 December. Pilot target is January 2027. This list is for the owner and whoever builds next. It sits alongside the [plan](budaya-go-plan-2026-11-14.md), [vision](../history/vision-and-roadmap-2026-11-14.md) and [product shape](../product/product-shape-2026-11-14.md).

## Done and live

- Public README with a system diagram and a note for judges on the project's history.
- Sky over Beranda: the real sun and stars over the site, engraved ridges, and star figures checked against the Yale catalogue.
- Automatic theme follows the sun over the site and blends slowly through twilight.
- Place pages: an ink-print cover, a cross-section with real counts, and news linked to a place's regencies. Stewards pick the news places from the desk's own list.
- Core sample (`/contexts/:slug/lapisan`) and the trail on every wiki page.
- Wiki reading page: serif text, voice bar, numbered sources, review line. Wiki home: modules that appear only when backed by real data.
- Consistency pass: chips, tab fades, right rail, empty states, failed images.
- Loading no longer flashes above the page. Back leaves a page in one step.
- One Studio for operators, with tabs for the community and for agents and connections.
- Aksara's picker says why it is unavailable, and a literal "@aksara" without a chosen identity shows a hint.
- Agent sign-in from outside (key, device, five-minute credential) checked end to end. Writes are refused without a mandate.
- Deploys run from GitHub when `deploy/etnos.txt` (site) or `deploy/resident.txt` (Aksara resident) changes.

## In progress

- **Aksara answers:** an honest reply when it has no source, a reviewed-wiki search tool, and web search and page reading through the Agents SDK.
- **The Tentang ETNOS page** and **poll honesty:** totals only after five answers, and every result labelled "dari N penjawab di ETNOS".

## Before the proposal (18–19 November)

1. Aksara answering live in a thread, with a receipt. The owner needs to check the model gateway in Studio's job list.
2. Findings as posts: Aksara's "sa ketemu ini" posts with check buttons, built on typed blocks rather than free-form text.
3. The composer can attach a place, so a story told from a core sample lands in that place.
4. Guided setup with Aksara as a conversation. Run it simulated first, then for real.
5. Real content: three to five places, three or four reviewed pages with real sources, one or two real polls. Remove the test copy.
6. Fresh screenshots and a short screen recording for the proposal.
