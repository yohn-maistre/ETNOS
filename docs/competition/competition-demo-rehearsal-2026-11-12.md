## The story to rehearse

1. **Arrive and explore.** A fresh visitor sees the wordmark morph into the dismissible welcome dialog. Close it and read a public conversation, compact Sorotan and current news. Open a public link directly to demonstrate that reading is not gated by signup. At 320/390px the bottom navigation stays reachable; the app has one progress line.
2. **Join and write.** Use the real AT provider sign-in. Open Posting from a community and check its destination. Format a short passage, add a permitted image with alternative text, preview, then publish. Editing and an ordinary child reply must preserve formatting. Private-to-public destination changes still require an explicit audience decision.
3. **Inspect a source.** As the actual community steward, open Studio → Sumber. Check the configured feed and inspect its actual item/canonical link and rights. ANTARA's initial registration is link-only: a headline is not evidence that the agent read the whole article. Do not invent an excerpt or change rights to make the demo more impressive.
4. **Create a Wiki starting point.** Studio → Penghuni shows the current identity, grants and task budget. Run a source digest first to verify the real hosted route; then request Catatan pengetahuan when there is sufficient permitted evidence. Enable the separate Wiki invitation option if a native announcement is wanted. Open the resulting provisional page in Wiki, inspect sources/TOC/review state, and show the human proposal/review path. A generated note is not automatically an accepted article.
5. **Ask the actual Aksara identity.** Enable public requests in the resident settings. In a public local community, type `@aksara`, choose the community or ETNOS identity, and inspect the removable request chip. Publish a concise question about an available source. The thread must show a real queue state followed by an actual child reply and canonical citations. Open Studio activity to inspect the model/result receipt. A literal mention without selecting an identity must remain an ordinary post.
6. **Show a useful stop.** Cancel a queued request, or pause the relevant agent participation before another explicitly labelled test question. Show a stopped/unavailable state and ordinary discussion continuing. Do not revoke a real community's live sources just to manufacture a failure shot. Isolated tests cover withdrawal, permission loss and interrupted work.
7. **Take an everyday next step.** Create a clearly labelled test offer/request, inspect its same canonical price/status on the community/profile/catalogue surfaces, open the actual enquiry route and mark it fulfilled. Existing native polls and sponsored work can support the discussion; they do not imply representative polling or institutional verification.

Use the public commons as the primary stage. A protected language room can demonstrate ordinary invitation/membership boundaries using two consenting accounts; never open private cultural originals, real personal data or internal Node memory during a recording. A public place/language context is a discovery lens, not membership in a private room.

## Live operator step

The assistant can deploy and inspect public routes, but currently has no connected signed-in owner browser. It must not extract OAuth secrets, impersonate the owner or deploy an authentication bypass to activate the resident. After the matched interaction release, the owner signs into ETNOS and opens Studio for a community they actually manage.

If no resident is configured, use the existing **Siapkan Aksara · 24 jam** flow with explicit source/automation choices. Otherwise inspect the current posting/editorial grants; renew only through the ordinary explicit controls when needed. Run **Ringkasan sumber** and report the activity state, visible result link and model label. An actual abstention/unavailability is a valid outcome to diagnose; an installed binding or a synthetic test is not a hosted inference receipt.

Then enable **Terima pertanyaan publik melalui @aksara** and save. A sitewide identity is optional for the first rehearsal. If used, the instance steward designates its actual home and public source coverage. Each extra destination requires a separate explicit admission/reply grant, bounded at 24 hours and three replies per hour; the local community Aksara remains distinct. These controls do not grant private access, Wiki acceptance or moderation.
