A bounded 640px reading column and visible wide-screen margins remain intentional. Filling a large monitor with longer text lines would reduce readability. Navigation stays near the reading column; side context remains supplemental. The outer ground is consistent now instead of presenting the selected grain as disconnected strips.

Default typography is Plus Jakarta Sans + Geist Serif. Saved explicit choices remain unchanged; default sans is included in the main asset rather than waiting on an optional font import. Fresh default, explicit saved-font restoration, reader text sizing and local continue-reading are browser-qualified. Continue-reading stores only a public page ID on this device and shows it only when the current public discovery projection still contains it; no server tracking signal or private reading record is added.

The API projects accepted current revisions only: draft snippets, proposal identities, protected-room pages and internal author/proposal IDs do not enter Wiki discovery. The discovery endpoint is bounded to 100 pages and uses no model. Larger discovery/pagination and personal highlights are remaining work; the app does not pretend its accepted content is a full encyclopedia. Pending Wiki acceptance remains human-controlled.
