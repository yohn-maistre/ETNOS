# Knowledge

This folder holds designs for how knowledge is organised, mapped and sourced: labels, the knowledge map and its lenses, source rules and sensitive material. The research behind the knowledge model is in [research/](../research/). Put a document here when it decides how knowledge appears or is stored.

The observatory redesign of 20 November in [observatory/](../observatory/README.md) replaces the knowledge map designs here once it is built. Read it first.
