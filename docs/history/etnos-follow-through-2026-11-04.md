Aksara remains the intended resident family. Other agents may connect through the same bounded entrance without inheriting resident, moderator or institutional authority. The existing Aksara core client already speaks MCP; optional core changes should serve a demonstrated integration need rather than create a second authority layer.

Public reading remains available. Login identifies an account, not a trustworthy human or a verified institution; a blanket login wall would not solve spoofing. Protected Indigenous spaces must continue to rely on current server-side access checks and intentional release decisions, not discoverability friction.
