# Lessons and things to remember (20 November 2026)

Internal notes for whoever works on ETNOS next, people or agents. Short on purpose. Newer notes go on top.

## Design

- **DESIGN.md** at the repo root documents the visual system, named Grafit: tokens, type scale, rows, pills, cover wash, panels and the 3D map. `.impeccable/design.json` is its sidecar. Update both when the system changes.
- **Dates.** Proposal, video and deck are uploaded on 26 to 27 November; the BUDAYA GO! showcase is 18 to 19 December. Some older docs still say 4 to 5 December.
- **Register.** The UI follows Threads and X: heavy titles (700 to 800), 15 to 16px body, rows with 14px vertical padding and a hover fill that runs to the column edges, pills for choices, thumbnails on the right (76px, 14px radius). Heavy rules, serif word specimens and open hairline lists made Jelajah look like an old blog. Do not bring them back.
- **Vary the components per section.** Jelajah uses a washed news lead with two smaller cards, rows with thumbnails, a talked-about list, topic pills, community rows with avatars and a Lihat pill, a place scroller and language chips. One rhythm, different shapes.
- **Use the libraries we already have** (shadcn-svelte, bits-ui) wherever they fit. Pages that cannot import them, like the identity host's server-rendered pages, copy the shadcn markup and values by hand (`packages/pds/src/host/pages.ts`).
- **Cover cards** use one primitive, `apps/web/src/styles/cover-wash.css`: full-bleed art, a dark wash from the bottom, white meta line and heavy headline. The lowest measured contrast was 7.76:1.
- **Appearance.** Grafit is the default base, Serat (`grain`) the default texture, and the theme follows the time of day until the reader picks one. `APPEARANCE_VERSION` in `appearance.svelte.ts` moves older saved settings to the new default once. Bump it only when a default must reach existing readers.
- **No sidebar toggle on desktop.** The sidebar stays put; phones open it from the dock's Menu.
- **Copy** follows `docs/voice.md` and `docs/naming.md`. Use eyebrows rarely, and only where they fit visually.
- **Impeccable.** PRODUCT.md now exists at the repo root, and the Jelajah direction is in `.impeccable/surfaces/`. Run the detector on changed UI files with `/root/.claude/skills/impeccable/scripts/impeccable detect --json <files>`. The finish-reviewer agent is not available in this harness, so the review runs in the same thread from screenshots.

## Technical

- **Identity host forms need `referrer-policy: same-origin`.** With `no-referrer`, browsers send `Origin: null` and the CSRF check rejects the form ("Permintaan ditolak").
- **Sign-up through our own host** sends `prompt=create`. The host's sign-up form carries `client_id` and `request_uri`, so after sign-up the new account goes straight to consent, where the password is asked again. `masuk=1` and `buat=1` switch between sign-in and sign-up.
- **Two invite layers exist.** ETNOS enrollment is open (`ETNOS_ENROLLMENT_MODE` in `wrangler.web.jsonc`). The identity host needs a code from `POST /admin/invites` with the operator token. Every host account writes a permanent DID to plc.directory, so open host sign-up needs a daily cap first.
- **The shell intercepts link clicks** for client routing. A component that handles a click itself calls `preventDefault()`, and the shell respects `defaultPrevented`.
- **Knowledge graph coordinates** run from -1 to 1, and outliers are clamped to the edge. `WikiFront.svelte` mixes each value with its rank so nodes do not pile up on the border.
- **Cloudflare accounts.** Durable Object data cannot move between accounts. Moving the identity host to a new account means re-creating it and updating each account's PLC record. The `*.etnos.space/.well-known/atproto-did` route must stay in the account that owns the etnos.space zone, as a small proxy.
- **West Papua Watch transplant.** The full engine is about 25 to 30 days of work and does not fit the free tier as built (`docs/news/news-transplant-plan-2026-11-20.md`). Before the demo, read WPW's existing clusters instead.

## Working together

- **The web app has its own tests.** CI runs `npm test` in `apps/web` too (`node --test tests/*.test.ts`). Node resolves imports there literally, so relative imports in `.ts` files that tests reach need the `.ts` extension. Run it before committing alongside the root checks.
- **The tree is shared.** Stage by explicit path, never stash or reset others' work. When a push is refused because a helper pushed first, `git pull --rebase origin main` and push again.
- **Commit trailers** go on their own line after a blank line. One helper commit put the trailer in the subject line.
- **Screenshots.** Run `npx vite --port 5179` in `apps/web`. In Playwright, route `/v1/` and `/auth/` requests to etnos.space (example: the scratchpad `wiki.cjs`). Helpers sometimes stop the dev server, so check it is up before shooting.
- **Stale test.** `apps/web/tests/browser/app-shell.mjs` still expects old Jelajah classes (`.explore-conversation`). It is not part of `npm test`; update it when the browser suite is next run.
- **Deploys.** Append a line to `deploy/etnos.txt` (date plus a letter) and push to main; the workflow deploys on that file.
