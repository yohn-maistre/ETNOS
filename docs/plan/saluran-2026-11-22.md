# Saluran: how photos, sound, 3D and time feed the Ensiklopedia

*22 November 2026. Design only, nothing here is built beyond the text saluran. It turns the brainstorm backlog (task #110) into one modular shape, so any later pipeline plugs into the same place. Builds on [one-page-system-2026-11-21.md](one-page-system-2026-11-21.md) §13 and [../research/language-from-nothing-2026-11-21.md](../research/language-from-nothing-2026-11-21.md).*

## 1. The frame

The frame stays **percakapan menjadi pengetahuan**. It is plain, it is true of every modality, and it says the order: people share first, knowledge comes after. Underneath it sits one engineering rule, **satu pintu** (one door): every modality enters through the same door, a question that members answer in Periksa. No pipeline writes to the Ensiklopedia or the Kamus directly.

## 2. The contract

A **saluran** is a module that reads one Jejak (a post, photo, clip or capture) in a community that has switched it on, and returns zero or more **usulan** (proposals):

| Field | Meaning |
| --- | --- |
| `jenis` | `kata` (a Kamus question), `tentang` (this Jejak is about entry X), `entri-baru` (a new entry draft), `nilai` (a value on an entry, such as a local name or a date) |
| `target` | An existing entry slug, or a draft with its global key (GBIF, Glottolog, Concepticon, Wikidata) |
| `bukti` | The Jejak, the exact span or region, and the module's reason in one sentence |
| `keyakinan` | The module's score. Below the community's threshold the usulan is dropped, never shown |
| `saluran` | Module name and version, so every published fact can be traced back |
| `lisensi` | The licence of anything the module copied in (a reference photo, a name list) |

Each usulan becomes one Periksa card, or one tap question in the post ("Ini *Ipomoea batatas*?"). What happens after a yes:

- **The entry exists**: the Jejak is marked *tentang* that entry and appears under its Percakapan. A photo can also be offered to the entry's Penampil, which asks the author first.
- **The entry does not exist**: an `entri-baru` draft waits for the community's quorum, then gets a page with the Jejak as its first source.
- **A word or value**: it goes to the Kamus or the entry's fields with the Jejak as evidence.

Rules every saluran follows:

1. A steward switches each saluran on per community. Off by default.
2. Private communities use only modules that run on the community's own machine (owner's rule). A hosted API never sees private media.
3. The output is always a question. A wrong guess costs one tap of *Bukan*.
4. Location: EXIF GPS is stripped on upload by default. A place is attached only when the author picks one. Species that are hunted or traded (cenderawasih, kakatua, some orchids) are shown at regency level at most.
5. Withdrawal: deleting the Jejak withdraws its usulan, and removes it as evidence from anything it supported.

## 4. 3D, from capture to Penampil

Two paths, one store.

1. **Bring a capture** (first). A member scans with a phone app and uploads the exported `.spz`, `.ply` or `.glb`. ETNOS checks size and type, stores it in R2, and the Penampil renders it with Spark. Cheap, works now on the free tier.
2. **Train from video** (later, on an Aksara Node with a GPU).
   1. Upload a 30–90 second walk-around video.
   2. Extract sharp frames (ffmpeg, about 2 per second, drop blurred ones).
   3. Solve camera poses with COLMAP or GLOMAP.
   4. Train Gaussian splats with an open trainer (gsplat or Brush), 7k to 30k steps.
   5. Compress to `.spz`, render a poster image, store both in R2.
   6. Optional: extract a mesh for printing or Sketchfab.

   The job runs as a queue item with progress in the post. A failed solve returns a plain message ("Video terlalu cepat, coba putar lebih pelan").

No generative image-to-3D for heritage objects. A model that invents the back of a carving is fabricated content. Existing public models can be linked from Sketchfab with their licence shown.

## 5. Order, after the pause

1. Photo upload in posts with EXIF stripping (shared by Foto and 3D).
2. The `usulan` shape in code, with Teks moved onto it so there is one path.
3. Foto tumbuhan on one test community.
4. Voice notes (#69), then Suara.
5. 3D bring-a-capture.
6. Waktu.
7. 3D training on an Aksara Node.
